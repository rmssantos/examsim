# AZ-500 is transitioning to SC-500

## Draft copy

AZ-500 retires on 31 August 2026.

SC-500 is not simply a new name for the same study plan.

Microsoft describes SC-500 as the Cloud and AI Security Engineer certification.
Its current study guide spans identity and governance, storage/databases/network,
compute, and security posture.

The compute domain now explicitly includes AI security topics such as Microsoft
Entra Agent ID, AI Gateway in API Management, Foundry guardrails, and monitoring
AI security in Defender for Cloud.

That changes how I would build practice content. Relabelling an older Azure
security bank would hide the most important delta.

objectives and measuring interest before deciding what enters the next content
